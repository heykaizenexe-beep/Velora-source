# Velora 0.9.158

## Новое в 0.9.158: Velora Editorial и перелистывание

### Основная тема по референсам

Тема с постоянным ID `classic` получила **новый отдельный главный экран** `EditorialHomeView.java`: крупные заголовки с засечками, мягкий молочный фон, пастельные поверхности, карточку текущей книги, прогресс чтения и горизонтальную коллекцию обложек. Сохранена **одна штатная нижняя навигация** Compose вместо двух дублирующих; для основной темы в ней используются плавные векторные контуры значков. Данные библиотеки используются из существующего `HomeBinding` и `BookRepository`; нажатие и долгое удержание обложки используют старые работающие действия. Основная тема намеренно **светлая**, как в референсах, независимо от ночного режима телефона; оформление самих страниц чтения остаётся отдельным. Тёмный вариант основного интерфейса можно добавить позднее как пользовательский выбор. Устанавливать новые библиотеки или шрифты не требуется.

В выборе оформления тема переименована в **«Velora · Основная»**; в каждой карточке темы показаны пять цветовых образцов. Идентификаторы тем не менялись: `pixel_cat_crt`, `cover_gallery`, `noir_journal` продолжают работать по своим маршрутам. **Сами экраны чтения и их палитры не наследуют цвета главного экрана.**

### «Как в книге» — работа над надёжностью

- У края можно **задержать палец перед движением**: увеличено время удержания для края листа до 1,8 с. Внутри текста обычное долгое нажатие по-прежнему принадлежит выделению текста.
- Во время подготовки соседних страниц **предыдущая теперь важнее необязательной второй следующей**: при отмене движения и возвращении назад кэш по возможности уже готов.
- Сохраняется существующий расчёт сгиба по пальцу, подготовка соседних EPUB/FB2-страниц, визуальное ожидание Readium и защита первой страницы от перелистывания назад.
- Режимы чтения пояснены в настройках.
- Эмуляторный тест больше не пытается делать скриншот параллельно с ADB-жестом (это вызывало таймауты): проверяет кадры **после** завершения жеста, логи распознавания и результат обоих направлений. Отдельный JVM-тест проверяет долгое удержание края, отмену и работу выделения текста. Добавлена проверка основной темы на настоящем Android-эмуляторе. Перед скриншотами тест умеет закрыть **только системное окно зависшего Pixel Launcher**, которое иногда перекрывает здоровую Velora на CI; окна ошибок Velora не маскируются.

**Ограничение:** автоматическая проверка не доказывает отсутствие каждого визуального рывка на реальных устройствах. В частности, первая холодная страница или смена главы могут потребовать времени для создания снимка; проверяйте это на телефоне.

### Сборка и обновление на Windows

В PowerShell, открытом в существующей папке проекта:

```powershell
git status
git pull --ff-only origin main
.\\BUILD_APK.cmd
```

APK: `build-output\\Velora-CRT.apk`. Если `git status` показывает локальные правки, сначала сделай их резервную копию. Релизной подписи пока нет: это тестовая сборка, как и 0.9.157.

## История: Velora 0.9.157

## Что изменилось в 0.9.157

- **Дневник «Картотеки»**: меню «+» теперь предлагает заметку, цитату или фотографию. У цитат собственный тип `quote`, курсив и декоративные кавычки. Цитаты можно редактировать, двигать, менять размер, бумагу и угол поворота; отмена последней операции сохранена. Старые элементы остаются совместимыми с `scrap_v2_`.
- **Единый дизайн**: `VeloraDesign.java` содержит общие размеры интерактивных областей (48dp), шрифты, базовую палитру «Картотеки» и длительности переходов. Параметры использованы в дневнике, на главном экране и в выборе тем; индивидуальные оформления других тем не заменяются.
- **Модернизация**: создан отдельный проект Android Studio `modern-android/` с `:app` и `:reader-core`. Ядро прямо компилирует шесть оригинальных Java-классов чтения и запускает пять JVM-регрессий без дублирования исходников. `:app` — только DEV-оболочка с отдельным applicationId, не читалка. Рабочий APK по-прежнему выпускает `rebuild.py`. См. `modern-android/README.md` и `docs/MODERNIZATION.md`.
- **Подпись**: `--release` намеренно заблокирован до безопасной настройки релизного ключа, см. `docs/RELEASE_SIGNING.md`. APK сборки остаётся тестовым.
- **Проверки**: `python3 tools/check_journal_design.py` и обновлённый `tools/check_editorial.py`.

### PowerShell: получить изменения в уже существующую папку

Открой PowerShell **в папке Velora с файлом BUILD_APK.cmd**:

```powershell
git status
git pull --ff-only origin main
.\BUILD_APK.cmd
```

Если в папке есть незакоммиченные изменения, сначала сохрани их: не используй `git reset --hard`. Готовый файл: `build-output\Velora-CRT.apk`. Для обновления установленной версии важна совместимость подписи (см. ниже).

## Архив документации: Velora 0.9.147

Проект восстановлен из APK. В нём есть редактируемый Java-код доработок, ресурсы и smali приложения и Readium. Сборку запускает `rebuild.py`, в том числе из терминала Android Studio.

## «Картотека» — Newspaper Editorial Edition

В версии 0.9.142 переработаны **цвета, заголовки, газетная шапка, кнопки, фильтры и оформление карточки выбранной книги**. Карусель настоящих объёмных обложек, её жесты, позиционирование и переход к дневнику сохранены.

Основа оформления — светлая книжная бумага (#F3EEE5), типографская краска (#302620), тонкая рамка (#C9BDB0) и приглушённый красно-терракотовый акцент (#A94F3B). Для заголовков используются системные шрифты Android с засечками; для управления — системный sans-serif. Никакие сторонние шрифты или отдельные ZIP-архивы для сборки больше **не нужны**.

При локальной сборке скрипт удаляет из декодированных ресурсов оставшийся Schueler SuperHyperXP Plus из предыдущих версий (если он есть), чтобы этот GPLv3-шрифт не оказался в новом APK. Остальные темы и шрифт текста книги остаются отдельными.

## Отдельные темы страниц в читалке (0.9.143)

В настройках чтения четыре самостоятельных варианта: «Светлая», «Сепия», «Тёмная», «Газета». Их цвета **не зависят от оформления всей Velora**. Тёмная использует фон #242629 и текст #E9E8E4, «Газета» — фон #F3EEE5 и текст #302620. Цвета сепии сохранены. Настройка «Газета» сохраняется отдельно, не подменяя сепию или выбор темы приложения.

## Лёгкая газетная фактура «Картотеки» (0.9.144)

Только главный экран темы «Картотека» теперь использует `NoirNewspaperPaper.java`: тёплый базовый цвет сохранён, поверх добавлено едва заметное зерно газетной бумаги и полупрозрачные имитации колонок лишь по краям. Плотность печатных линий около 4% непрозрачности, зерно ещё слабее. Центр карусели оставлен максимально чистым; декоративные потёртости, рваные края и большие буквы отсутствуют.

Текстура рисуется через повторяющуюся маленькую битмап-плитку с фиксированным seed и не пересчитывается при перелистывании книг. **Цвета страниц чтения, независимый режим «Газета», дневник и остальные темы не затронуты.**

## Регулировка газетной текстуры «Картотеки» (0.9.145)

На экране «Темы оформления» выберите «Картотека»: прямо внутри её карточки появится ползунок **«Выраженность газетной текстуры»** от 0 до 100% с мини-просмотром. **0%** даёт ровный бумажный фон; **35%** — прежнюю едва заметную текстуру из 0.9.144 (значение по умолчанию); **100%** — более отчётливую, но всё ещё полупрозрачную фактуру.

Изменения применяются при перемещении ползунка и запоминаются в отдельных SharedPreferences `velora_cartoteka_appearance`, ключ `newspaper_texture_strength`. Экран «Картотеки» подписывается на изменение этой настройки и обновляет только свой фоновый Drawable без пересоздания карусели или загрузки книги. Тема страниц «Газета» в читалке и все остальные темы приложения независимы.

## Обновление чтения и реальная фактура (0.9.146)

**«Картотека».** Вместо синтетического зерна как основного слоя используется настоящая фототекстура бумаги, сохраняемая в `decoded/assets/noir/newsprint-paper.jpg`. Фото из Wikimedia Commons, «Текстура бумаги», автор Iroi su, 2010 год, лицензия **CC0 1.0**: https://commons.wikimedia.org/wiki/File:Текстура_бумаги.jpg. Фотография мягко смешивается с молочно-бумажным цветом, прозрачность регулируется ползунком 0–100%; ноль полностью отключает изображение. В читалке изображение не используется.

**Настройки чтения.** В разделе оформления четыре видимые палитры **«День», «Сепия», «Ночь», «Газета»**. Сами кнопки показывают настоящий цвет бумаги и текста; выбранная палитра отмечается галочкой. Переключатели «Обычное / Как в книге» теперь расположены в одной компактной строке, без громоздких карточек.

**Совместимость с Readium.** Для газетного фона используются стандартная тема `LIGHT` движка плюс независимые пользовательские цвета фона/текста. Значение `NEWSPAPER` сохраняется как настройка Velora и используется в выборе оформления, но не передаётся в навигатор как неподдерживаемая тема. Это устраняет вероятную причину аварийного завершения при применении газетной палитры.

## Улучшения 0.9.147: компактные настройки и более видимая бумага

**Читалка.** Пять высоких настроек размера шрифта, межстрочного интервала, полей и абзацев заменены компактными строками: название, горизонтальный ползунок и числовое значение теперь стоят на одной линии. Сохранены прежние диапазоны и обработчики применения. Выбор темы страницы содержит цветные образцы четырёх фонов — «День», «Сепия», «Ночь» и «Газета», с отметкой выбранного; в Readium для «Газеты» применяется совместимая базовая светлая тема с отдельными цветами, чтобы избежать прежнего падения.

**Картотека.** Фотография настоящей бумаги из Commons (CC0) стала заметнее: прозрачность фотографии при сохранённом 35% теперь выше, а значение по умолчанию для новых установок — 45%. Ползунок 0–100% по-прежнему позволяет выключить текстуру или усилить её. Читалка эту фотографию не использует.

## Собрать APK на Windows

1. Установи **JDK 21** и **Python 3.10 или новее**. При установке добавь их в PATH. Если Studio уже установлена, можно использовать её JDK 21, указав путь к ней в переменной `JAVA_HOME`.
2. Распакуй ZIP в новую папку с коротким путём или клонируй репозиторий. Открой папку Velora с файлом `BUILD_APK.cmd` в терминале. Проверь `java -version` и `py -3 --version`. Если команда `py` отсутствует, проверь `python --version`.
3. Запусти `BUILD_APK.cmd`. Первая сборка скачает инструменты. Готовый файл появится в `build-output\Velora-CRT.apk`.

```powershell
cd C:\dev\Velora
.\BUILD_APK.cmd
```

Android SDK для этой сборки устанавливать отдельно не нужно. Для запуска APK в эмуляторе его можно перетащить в окно эмулятора. Для установки на телефон передай APK на устройство и открой его.

На Linux та же сборка запускается командой `python3 rebuild.py --compile-home --incremental`. Когда нужен чистый прогон, запусти `python rebuild.py --compile-home` без `--incremental`. После сборки можно запустить `python tools/verify_abi.py build-output/Velora-CRT.apk` для проверки ссылок между классами в APK.

## Где менять файлы

| Что меняешь | Где искать |
| --- | --- |
| Главная «Картотеки» | `native-source/app/velora/reader/crtui/NoirHomeView.java` |
| Обложки, карточка книги и список библиотеки | `NoirCoverDeck.java`, `NoirBookTicket.java` и `NoirCatalogSheet.java` в той же папке |
| Дневник и разворот | `NoirSpreadActivity.java` и `NoirScrapbookView.java` в той же папке |
| Анимация перелистывания | `PageTurnController.java` и `PageCurlView.java` в той же папке |
| Смежная логика Readium, в том числе выделение текста | `decoded/smali_classes20/org/readium/r2/navigator/` |
| Изображения, строки, ресурсы | `decoded/assets/` и `decoded/res/` |
| Номер и название версии | `decoded/apktool.yml` → `versionCode` и `versionName` |

`decoded/smali_classes23/` создаётся заново из `native-source/` при сборке. `compile-stubs/` нужен компилятору для разрешения ссылок. Готовые файлы `decoded/classes*.dex` содержат библиотеки. Сборка автоматически восстанавливает зависимости из `original/media-libraries-smali.tar.xz` рядом с исходниками Readium.

## Подпись APK

Сборка ищет ключ предыдущих тестовых версий в `signing/velora-crt-test.p12`. Для установки поверх ранее выданных тестовых APK скопируй этот файл из своего архива `Velora-Noir-Journal-PROJECT-0.9.127.zip` в папку `signing` рядом со скриптом. Для следующего обновления увеличь `versionCode`.

Если старого ключа нет, скрипт создаст `signing/local-test.p12` и будет повторно использовать его для твоих локальных сборок. APK с новым ключом не установится поверх версии с другой подписью. Чтобы сохранить данные читалки, сначала возьми старый ключ. Для выпуска приложения используй отдельный ключ и храни его вне Git.

Справка по подписи и обновлениям — [Android Developers](https://developer.android.com/studio/publish/app-signing).

## Git и GitHub

Создай пустой приватный репозиторий на GitHub. Затем открой PowerShell в распакованной папке с `BUILD_APK.cmd`. В четвёртой строке подставь HTTPS-адрес своего репозитория.

```powershell
git init -b main
git add .
git commit -m "Исходники Velora 0.9.143"
git remote add origin https://github.com/USERNAME/Velora-source.git
git push -u origin main
```

Дальше правки сохраняются через `git add`, `git commit` и `git push`. Правила в `.gitignore` исключают результаты сборки, кэш инструментов, восстановленные зависимости и локальные ключи.
